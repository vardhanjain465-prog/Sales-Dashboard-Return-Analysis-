# Sales-Dashboard-Return-Analysis-
Return Analysis Dashboard
This Power BI return analysis dashboard evaluates product return patterns across 25,728 total orders and 96,00,362 in total sales, highlighting key operational drivers across product categories, fulfillment timelines, customer profiles, and geographic regions. Maintaining an overall return rate of 4.19% (1,079 total returns), the visual analysis reveals that Office Supplies accounts for the highest return volume at 533 units—nearly double that of Technology (283) and Furniture (263)—while return volume peaks sharply for orders fulfilled within 4 shipping days (306 returns). By segmenting category-level return percentages across regional markets like USCA, Asia Pacific, and Europe alongside monthly profit and sales trends, this dashboard provides logistics and customer support teams with actionable insights to reduce return rates and protect overall profitability.
